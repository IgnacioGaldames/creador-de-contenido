# 🚀 ¿Primera vez? Empieza aquí

## Paso 1 — Instala Node.js

Descárgalo desde **[nodejs.org](https://nodejs.org/)** (versión LTS) e instálalo con el asistente.

> **Importante:** Después de instalar, **reinicia tu computador** o cierra y abre todas las ventanas de terminal/VS Code.

Para verificar que quedó instalado, abre una terminal nueva y escribe:

```bash
node --version
npm --version
```

Ambos deben mostrar un número de versión (ej: `v20.12.0`).

---

## Paso 2 — Clona el proyecto con SourceTree

Si aún no lo has hecho, clona este repositorio desde Bitbucket usando SourceTree.

---

## Paso 3 — Inicia la app (1 clic)

| Sistema | Archivo | Acción |
|---------|---------|--------|
| 🪟 Windows | `iniciar_proyecto.bat` | Doble clic |
| 🍎 macOS | `iniciar_proyecto.command` | Doble clic (si bloquea: clic derecho → Abrir) |

El script instala dependencias automáticamente la primera vez y abre la app en **http://localhost:5173/**.
